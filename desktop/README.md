# Переносимая версия

Запустите `build-portable.ps1` из корня проекта. Готовая программа появится в
`desktop/dist/Листок.exe`. Папку `desktop/dist` можно перенести целиком.

Доска и картинки сохраняются браузерным движком в `app-data` рядом с EXE.
Автокопии находятся в `app-data/backups`: снимки доски в JSON, оригиналы
картинок в `backups/assets`. Один оригинал хранится один раз и используется
несколькими снимками. Удалять отдельные файлы из `backups/assets` нельзя:
они могут понадобиться старым снимкам.

Чтобы перенести доску из прежней браузерной версии, скачайте в ней копию
`.listok` и восстановите её через меню «Бекап» в переносимом приложении.
