# Huiro для Windows

Запустите `build-portable.ps1` из корня проекта. Готовая программа появится в
`desktop/dist/Листок.exe`. Папку `desktop/dist` можно перенести целиком.

Доски, картинки WebView2 и автокопии сохраняются в папке данных пользователя
Windows, обычно `%APPDATA%\ru.listok.board`. Их не нужно переносить вместе с EXE,
и они не удаляются при перемещении программы. Автокопии находятся в
`backups`: снимки доски в JSON, оригиналы картинок в `backups/assets`. Один
оригинал хранится один раз и используется несколькими снимками. Удалять
отдельные файлы из `backups/assets` нельзя: они могут понадобиться старым
снимкам.

Для передачи программы другому пользователю достаточно отправить EXE. У каждого
пользователя будут свои доски и картинки в его папке данных.

Если вы обновляете старую версию, которая хранила данные в `app-data` рядом с
EXE, не удаляйте эту папку: старые доски останутся там. Сначала восстановите их
в новой версии через резервную копию `.listok`; после проверки старую папку можно
удалить вручную.

Чтобы перенести доску из прежней браузерной версии, скачайте в ней копию
`.listok` и восстановите её через меню «Бекап» в переносимом приложении.
